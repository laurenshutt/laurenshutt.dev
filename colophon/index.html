About the Site

I first built this site in 2022 to showcase my work and a little bit of my personality during job searches. After four years of growing as a developer, I redesigned in 2026. I continue to tinker with it and don’t think I’ll ever consider it “done.” As a recovering perfectionist, my mantra is that anything worth doing is worth doing imperfectly.

Capsurium

Inspired by Maggie Appleton , I wanted to expand this site into a digital garden; but instead of her growth stages to show how complete or comprehensive a post is, I’m using the evolution stages of Tamagotchi! Tamagotchi Capsuriums (little capsule terrariums) have been sold by Bandai, so I that’s what I decided to call the “garden.”

Design

I wanted the site to convey an early-2000s analog whimsy and evoke the playfulness the Internet seemed to have when I first started coding. I went with high-saturation , synthetic colors reminiscent of the Y2K Futurism aesthetic .

Typography Headings are set in Silkscreen by Jason Kottke. Body text is set in Lato , by Łukasz Dziedzic. Both are self-hosted via Google Fonts Files on Github .

Features

Background grid

A grid is dynamically created on the homepage with interactive “cells” that light up in a randomly-selected cover when the mouse moves over them. It is behind an overlay to keep the text readable, so the saturation of the cells changes depending on where they are on the page.

Windows

The homepage is divded into “window” sections that can expand to full screen, minimize to just the nav bar, and even disappear entirely when the “close” button is clicked.

Icebreakers

The “about” window has a button that allows the user to randomly select an icebreaker. The user can then choose to send the icebreaker via the contact form at the bottom of the page.

Implementation

My goal was to create an immersive, gamified UI using accessibility-aware components and lightweight, framework-free JavaScript.

Domain services My domain is registered through Porkbun , which also handles my DNS and email via its SMTP service. I use Gmail as my primary email interface.

Build and deployment The site is built locally with a static frontend using Vite to handle bundling and optimization. I deploy with a small shell script that first commits changes to GitHub , which acts as a remote backup and synchronization layer. Next it uploads the build to my Nixihost VPS using rsync , with each deployment saved as a timestamped release. It finally switches a symbolic link to point to the newest release, with old releases kept on the server for easy rollback.

The site is served using Nginx , with HTTPS handled by Let’s Encrypt .

Contact form My contact form is handled through FormSubmit , a form-to-email service that allows static sites to receive submissions without requiring a custom backend.

Web standards

  • I follow WCAG and use ARIA to enhance semantic clarity for assistive technologies.
  • For naming, I try to follow Yandex’s BEM (Block Element Modifier) conventions.

Metadata and discovery

  • I’ve implemented structured data using Schema.org , microformats , and microdata to expose meaningful relationships.
  • Open Graph provides rich link previews, and sitemap.xml and robots.txt files support search engine discovery.
  • A humans.txt file provides lightweight acknowledgement of authorship and tooling.

Privacy

I use Google Analytics to understand traffic patterns and improve performance. If you submit information through the contact form, it is processed by a third-party service for delivery to my email. I do not sell or share personal data.
